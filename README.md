# Face Recognition Attendance System (ระบบเช็คชื่อด้วยใบหน้า)

ระบบเช็คชื่อเข้าเรียนด้วยการตรวจจับและรู้จำใบหน้าแบบ Real-time โดยใช้ **FaceNet** สำหรับการสกัดคุณลักษณะใบหน้า (Embeddings) ร่วมกับ **SVM (Support Vector Machine)** ในการจำแนกตัวบุคคล พร้อมบันทึกประวัติการเข้าเรียนลงในไฟล์ Excel หรือ TXT และมีระบบแจ้งเตือนด้วยเสียง

## 📁 โครงสร้างโปรเจกต์
* `capture_face.py` : โปรแกรมสแกนเก็บใบหน้าเพื่อนำมาฝึกฝน (ตรวจจับมุมใบหน้าต่างๆ ปริมาณแสง และความเบลอของภาพก่อนบันทึก)
* `train_facenet.py` : โปรแกรมสกัด Face Embeddings และฝึกฝนโมเดล SVM Classifier
* `recognize_face_excel.py` : โปรแกรมสแกนใบหน้า Real-time และบันทึกประวัติลงไฟล์ Excel (`attendance.xlsx`)
* `recognize_face_txt.py` : โปรแกรมสแกนใบหน้า Real-time และบันทึกประวัติลงไฟล์ข้อความ (`face_log.txt`)
* `recognize_face.py` / `ex1_facr.py` : โปรแกรมทดสอบการจำใบหน้าแบบง่าย
* `dataset/` : โฟลเดอร์สำหรับเก็บภาพใบหน้าแยกตามโฟลเดอร์ย่อยของนักศึกษาแต่ละคน

## 🛠️ วิธีการใช้งาน

### 1. การติดตั้ง Library ที่จำเป็น
โปรดตรวจสอบว่าได้เปิดใช้ Virtual Environment แล้ว และติดตั้งโมดูลต่อไปนี้:
```bash
pip install opencv-python numpy scikit-learn tensorflow keras-facenet openpyxl
```

### 2. ขั้นตอนการเก็บรูปภาพใบหน้า (Capture Dataset)
รันไฟล์ `capture_face.py` เพื่อลงทะเบียนผู้ใช้ใหม่:
```bash
python capture_face.py
```
* ระบุ รหัสนักศึกษา (เช่น `66713927`) และ ชื่อ
* ระบบจะเปิดกล้องและเริ่มเก็บภาพ โดยแนะนำให้หันหน้าตรง ซ้าย ขวา เงยหน้า และก้มหน้า ตามคำแนะนำบนหน้าจอจนครบ 150 รูป

### 3. ขั้นตอนการเทรนโมเดล (Train Model)
เมื่อเก็บข้อมูลครบถ้วนแล้ว ให้รันไฟล์ `train_facenet.py` เพื่อฝึกฝนโมเดลให้จดจำรูปใบหน้าชุดใหม่:
```bash
python train_facenet.py
```
* เมื่อเสร็จสิ้น จะได้ไฟล์โมเดล `facenet_svm.pkl` และ `label_encoder.pkl`

### 4. การรันระบบเช็คชื่อ (Real-time Attendance)
คุณสามารถเลือกสแกนและบันทึกประวัติเป็น Excel หรือ Text File ได้ตามต้องการ:
* **บันทึกลง Excel (พร้อมระบบแจ้งเตือน Line และระบบป้องกันบันทึกซ้ำ):**
  ก่อนใช้งาน ให้ระบุ Line Token ในตัวแปร `LINE_TOKEN` ภายในไฟล์ `recognize_face_excel.py`
  ```bash
  python recognize_face_excel.py
  ```
* **บันทึกลง Text File:**
  ```bash
  python recognize_face_txt.py
  ```

## 📲 ระบบแจ้งเตือนผ่าน Line (Line Notify)
ระบบจะทำการส่งการแจ้งเตือนเข้าไปยัง Line กลุ่มหรือบัญชีของคุณครูพร้อมรูปถ่ายใบหน้าที่แสกนได้ทันทีเมื่อมีการเช็คชื่อสำเร็จ

### วิธีการเปิดใช้งาน Line Notify:
1. เข้าสู่ระบบที่เว็บไซต์ [LINE Notify](https://notify-bot.line.me/) ด้วยบัญชี Line ของคุณ
2. ไปที่หน้า **My Page** (หน้าของฉัน) และคลิกที่ **Generate token** (ออก Token)
3. ตั้งชื่อ Token เช่น `ระบบเช็คชื่อเข้าเรียน` และเลือกห้องแชท (หรือกลุ่ม) ที่ต้องการให้ส่งข้อความแจ้งเตือน
4. คัดลอก Token ที่ได้มา และนำมาใส่ในไฟล์ `recognize_face_excel.py` ที่บรรทัด:
   ```python
   LINE_TOKEN = "ใส่_LINE_TOKEN_ของคุณที่นี่"
   ```

## 🛡️ ระบบป้องกันการบันทึกข้อมูลซ้ำ (Duplicate Prevention)
โปรแกรมถูกพัฒนาขึ้นให้ป้องกันการเช็คชื่อซ้ำของบุคคลเดิมในวันเดียวกัน:
1. **ขณะรันโปรแกรม:** ระบบจะจำชื่อที่เช็คชื่อสำเร็จไว้ในหน่วยความจำ (`checked_today`) หากมีการแสกนซ้ำระบบจะไม่บันทึกซ้ำอีก
2. **ข้ามการรันโปรแกรม (Restart):** เมื่อเปิดโปรแกรมขึ้นมาใหม่ ระบบจะอ่านไฟล์ `attendance.xlsx` เพื่อดึงรายชื่อที่เคยเช็คชื่อในวันนี้มาไว้ในหน่วยความจำทันที ป้องกันไม่ให้แสกนซ้ำได้แม้ว่าจะปิดแล้วเปิดโปรแกรมใหม่
